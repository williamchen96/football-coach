# Glossary

Short definitions. The numbered files have the detail.

| Term | Definition |
|---|---|
| A gap, B gap, C gap, D gap | Spaces between offensive linemen, lettered outward from the center |
| Alert | A route thrown only when the pre-snap look gives it away |
| All-22 | The wide coaches' film view showing every player |
| Alley | The run-support lane between the force defender and the interior |
| Apex | A defender aligned halfway between the tackle and a slot receiver |
| Audible | A play change at the line of scrimmage |
| Backed up | Offense inside its own 10 |
| Bail | A corner showing press, then retreating to a deep zone at the snap |
| Banjo | A switch rule for man defenders against bunch and stack |
| Bear | A front covering the center and both guards |
| Blitz | An extra rusher; strictly, a defensive back rushing |
| Bootleg | The quarterback rolls away from a run fake. Naked means without a blocker in front |
| Boundary | The short side of the field |
| Box | The area around the offensive line; also an edge technique that keeps the ball inside |
| Bracket | Two defenders on one receiver, inside and outside or over and under |
| Bubble | An uncovered gap in a front; also a quick perimeter screen |
| Bunch | Three receivers aligned tightly together |
| Cadence | The quarterback's snap count |
| Check-down | A short outlet throw after the main reads are covered |
| Check-release | A back checks for a rusher, then runs a route |
| Chip | A brief block on a rusher by a releasing back or tight end |
| Cloud | Coverage in which the corner has the flat and force |
| Combo block | Two linemen on one defender, one of whom climbs to a linebacker |
| Conflict defender | A defender with both a run and a pass responsibility, targeted by RPOs and play-action |
| Contain | Responsibility for keeping the ball or the quarterback inside |
| Cover 0 to Cover 6 | Coverage families, named for the number of deep defenders. See `06-coverages.md` |
| Crack | A receiver's block down on an inside defender |
| Creeper | A four-man rush with a disguised rusher and a dropping lineman |
| Cutback | A run that bends behind the initial flow |
| Dime | Six defensive backs |
| Dog | A linebacker rushing |
| Double move | A route that fakes one break and makes another |
| Down block | A block on the defender to the lineman's inside |
| Draw | A run that begins with pass-protection looks |
| Duo | A gap run with two interior double teams and no puller |
| Edge | The end man on the line of scrimmage; an outside rusher |
| Eligible | A player allowed to catch a forward pass |
| EMOL | End man on the line of scrimmage |
| Empty | A formation with no back in the backfield |
| EPA | Expected points added |
| Explosive | A long gain: commonly 10 or more on a run, 16 to 20 or more on a pass |
| Field | The wide side of the field |
| Fire zone | A five-man pressure with three deep and three underneath |
| Fit | A defender's gap responsibility against the run |
| Flat | The short outside zone; also the route into it |
| Flood | Three receivers at three depths on one side |
| Force | The defender who turns a run back inside |
| Front | The alignment of defensive linemen and linebackers |
| Gap scheme | A run with down blocks and a puller, such as power and counter |
| Green dog | A man defender rushing when his man blocks |
| Gunner | The wide coverage player on a punt |
| Hard count | A cadence designed to draw the defense offside or reveal a blitz |
| Hash | The inbounds marks where the ball is spotted |
| High-low | Two receivers at different depths on one defender |
| Hinge | A back-side tackle's step-down and pivot on gap runs |
| Hole | The middle underneath zone; also the designed run lane |
| Hole shot | The sideline throw between a Cover 2 corner and safety |
| Hook | The inside underneath zone |
| Hot | A quick throw that replaces an unblocked blitzer |
| Jet motion | A receiver running flat across the formation at the snap |
| Kick-out | A block that drives the end man outward |
| Leverage | A defender's position, inside or outside, on a receiver or blocker |
| Log | A puller's block that hooks the end man inside |
| Man coverage | Each defender covers one receiver |
| Match (pattern match) | Zone coverage that converts to man by route distribution |
| MEG | Man everywhere he goes |
| Mesh | Two shallow crossers that rub; also the quarterback and back exchange point |
| Middle eight | The last four minutes of the first half and the first four of the second |
| Mike | Middle linebacker; also the defender the protection is set to |
| MOD | Man on demand: a corner plays man only if #1 goes deep |
| MOFC, MOFO | Middle of the field closed (one deep safety), open (two) |
| Mug | Linebackers walked up into the A gaps |
| Nickel | Five defensive backs; also the fifth back |
| One-gap, two-gap | A lineman responsible for one gap, or for the gap on either side of his blocker |
| Option route | A route whose break depends on the defender's leverage |
| Over, Under | Four-man fronts with the 3-technique to the strong side, or to the weak side |
| Palms | A Quarters variation in which the corner jumps #2 to the flat |
| Peel | A rusher leaves the rush to cover a releasing back |
| Personnel | The mix of backs, tight ends and receivers, or of defensive backs |
| Pin and pull | A perimeter run with down blocks and pullers |
| Pistol | The quarterback about 4 yards deep with the back behind him |
| Play-action | A pass that begins with a run fake |
| Press | Coverage at the line of scrimmage that jams the release |
| Progression | The order in which the quarterback reads receivers |
| Pull | A lineman leaves his position to block elsewhere |
| Quarters | Cover 4 |
| Rat (robber, hole) | A free underneath defender in man coverage |
| Reach | A block that gets outside a play-side defender |
| Red zone | Inside the opponent's 20 |
| RPO | Run-pass option |
| Rub (pick) | A route that screens a man defender |
| Sam | Strong-side linebacker |
| Scat | Five-man protection with the back released |
| Seam | The vertical lane up the hash; the route run there |
| Shade | A lineman aligned on a blocker's shoulder |
| Shell | The pre-snap picture of the safeties |
| Shift | Two or more offensive players resetting before the snap |
| Sight adjust | A receiver changing his route against a blitz |
| Sim pressure | Showing pressure and rushing four from unexpected spots |
| Sky | Coverage in which a safety has the flat and force |
| Slide | Pass protection in which linemen block a gap in one direction |
| Spill | Forcing a run wide by attacking blocks with the outside shoulder |
| Split | A receiver's distance from the formation |
| Squat | A Cover 2 corner sitting in the flat |
| Stack | Two receivers aligned one behind the other; a linebacker aligned behind a lineman |
| Star | The nickel back |
| Stem | A receiver's path before the break; a pre-snap shift by the defensive line |
| Stunt (twist, game) | Rushers exchanging lanes |
| Success rate | Share of plays that gain the yards needed to stay on schedule |
| Tampa 2 | Cover 2 with the Mike running the deep middle |
| Technique | A defensive lineman's alignment number |
| Tite | An odd front with ends in 4i techniques |
| Trail | Man technique behind and inside a receiver with help over the top |
| Trips, Trey | Three receivers to one side; Trey includes the tight end |
| Wham | A trap block by a tight end or H-back |
| Will | Weak-side linebacker |
| X, Y, Z, H | Split end, tight end, flanker, slot or H-back |
| Zone blocking | Linemen block areas and combine on defenders in their path |
| Zone coverage | Defenders cover areas of the field |
| Zone read | An inside-zone run with the quarterback reading the back-side end |
